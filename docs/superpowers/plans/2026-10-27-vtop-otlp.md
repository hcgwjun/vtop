# vtop OTLP 요청 추적 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** vLLM의 `--otlp-traces-endpoint`가 보내는 `llm_request` 스팬을 vtop이 직접 받아(프록시 없이, 클라이언트·vLLM 포트 변경 없이) 요청별 TTFT·큐·프리필·디코드·토큰을 Requests 표에 보인다.

**Architecture:** vtop이 `127.0.0.1:4318`에서 `POST /v1/traces`(OTLP/HTTP protobuf)만 받는 axum 라우트를 연다. protobuf는 `prost` 파생 구조체를 손으로 써서 필요한 필드만 읽는다(`opentelemetry-proto` 크레이트는 SDK까지 끌고 와서 안 씀). 스팬은 기존 `RequestLog`(1,000건 링)에 `Record`로 들어가고 Overview 하단 표와 Requests 탭이 그대로 보여준다. 프록시(`src/proxy/*`)와 그 의존성은 삭제한다. 시각은 서버 로컬 시간대(`libc::localtime_r`).

**Tech Stack:** axum 0.8, tokio, prost 0.14, libc 0.2, ratatui 0.30.

**Spec:** `docs/superpowers/specs/2026-10-27-vtop-design.md` — "Requests", "단축키" 절. 프록시 절은 이 계획으로 대체됨(스팬이 더 정확하고 클라이언트 변경이 없다).

## Global Constraints

- 스팬 수신기는 `127.0.0.1`에만 바인드. 기본 포트 4318, `--otlp PORT`로 변경. 바인드 실패는 TUI 전에 `Error: cannot bind otlp receiver on ...`로 종료.
- 응답은 항상 `200` + `content-type: application/x-protobuf` + 빈 본문(`ExportTraceServiceResponse` 빈 메시지). 파싱 실패도 200(vLLM이 재전송하며 큐를 키우지 않게).
- `llm_request` 이름의 스팬만 기록. 다른 스팬(로딩 등)은 무시.
- 시각은 로컬 시간대. 열 이름 `TIME`, 내보내기 파일명 `vtop-<YYYYmmdd-HHMMSS>.json`도 로컬.
- 수집기·수신기는 패닉하지 않는다(`unwrap`은 잠금에만). UI 문자열 영어. 커밋 끝 `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.

## Review Focus

1. 알 수 없는 protobuf 필드·다른 이름의 스팬·속성 누락(예: `time_in_queue` 없음)이 와도 패닉 없이 건너뛰고 아는 값만 기록. → Task 1 `unknown_fields_and_spans_are_skipped`.
2. 한 요청에 여러 스팬이 한 바디로 오면 전부 기록(배치). → Task 3 `batch_of_two_spans_gives_two_rows`.
3. 디코드 시간이 0(출력 토큰 1개)이면 tok/s는 n/a, 패닉·inf 없음. → Task 2 `tok_s_none_when_decode_is_zero`.
4. 본문이 protobuf가 아닌 쓰레기여도 200을 돌려주고 기록은 없음. → Task 3 `garbage_body_is_acknowledged_without_rows`.
5. 로컬 시간대가 KST일 때 표·파일명이 UTC+9로 찍힘. → Task 2 `local_time_uses_tz`.

### Task 2: Record를 스팬 기준으로 재정의, 로컬 시각

**Files:**
- Modify: `src/requests.rs`, `Cargo.toml` (`libc = "0.2"`)

**Interfaces:**
- Produces:
  ```rust
  #[derive(Debug, Clone, Serialize)] pub struct Record {
      pub id: u64, pub started_unix_ms: u64, pub request_id: String,
      pub prompt_tokens: Option<u64>, pub output_tokens: Option<u64>,
      pub ttft_ms: Option<f64>, pub queue_ms: Option<f64>, pub prefill_ms: Option<f64>, pub decode_ms: Option<f64>, pub e2e_ms: Option<f64>,
      pub max_tokens: Option<u64>,
  }
  impl Record {
      pub fn from_span(s: &Span) -> Option<Record>;  // name != "llm_request" → None; started = start_time_unix_nano / 1e6; e2e = gen_ai.latency.e2e, 없으면 end-start
      pub fn tok_s(&self) -> Option<f64>;             // output / decode_s, decode_s ≤ 0 → None
  }
  pub fn hhmmss_local(unix_ms: u64) -> String;        // "15:33:51", libc::localtime_r
  pub fn stamp_local(unix_ms: u64) -> String;         // "20261027-153351"
  ```
  `Status`, `path`, `model`, `stream`, `approx`, `duration_ms`, `hhmmss_utc`, `yyyymmdd_hhmmss_utc` 삭제. `RequestLog`/`SharedLog`/`CAPACITY`는 유지(`update`는 더 안 쓰이면 삭제).

- [ ] **Step 1: 실패하는 테스트** (기존 테스트 중 삭제 필드를 쓰는 것은 바꿈)
